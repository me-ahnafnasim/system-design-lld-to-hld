# Contributing

Keep it small, consistent, and reviewable.

1. One concept per file / folder.
2. Every pattern or case study needs:
   - `README.md` (problem → design → diagram → trade-offs)
   - Code (Java preferred) or `diagram.png` linked from `assets/diagrams/`
3. Use kebab-case for files and folders.
4. Update the parent `README.md` checklist when adding new content.
5. Open a PR — keep description to what + why.
