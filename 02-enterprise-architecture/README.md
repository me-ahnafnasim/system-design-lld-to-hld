# 02 — Enterprise Architecture

> How do all business, application, data, and technology systems fit together?

Scope: **whole organization**.

## Example — University Enterprise
```text
ERP, CRM, LMS, Website, Admission Platform,
Accounting, HR, Email, Identity, Data Warehouse
```

## Key concerns
- Application portfolio, technology standards, shared platforms
- Data ownership, integration standards, governance, long-term roadmap
- Business capability mapping, portfolio management, IT governance

## Frameworks
- TOGAF, Zachman, FEAF (reference only — don't memorize, understand intent)

## Checklist
- [ ] Portfolio inventory (no shadow-system surprises)
- [ ] Standards: identity, integration, data ownership
- [ ] Shared platforms identified (auth, notifications, analytics)
- [ ] 1–3 year roadmap direction

## Artifacts
- Portfolio map, standards one-pager, roadmap timeline
