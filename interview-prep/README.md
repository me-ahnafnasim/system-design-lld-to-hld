# Interview Prep

## 45-min HLD framework
1. Clarify (5) → 2. Estimate (5) → 3. API (5) → 4. Model (5) → 5. Design (15) → 6. Deep dive (7) → 7. Wrap-up (3)

## 35-min LLD framework
1. Requirements (5) → 2. Use cases (5) → 3. Classes (10) → 4. Diagram (5) → 5. Code (7) → 6. Extensibility (3)

## Checklists
- [ ] State quality attrs + CAP choice early
- [ ] Name owners for data + components
- [ ] Call out cross-cutting: auth, retry, observability
- [ ] End with bottlenecks + next scale step

## Revision sheets
- Patterns: Gateway/BFF/CQRS/Breaker/Retry per use
- GoF: 1-line intent + when-not-to-use per pattern
- Estimations: users → QPS → storage → bandwidth
