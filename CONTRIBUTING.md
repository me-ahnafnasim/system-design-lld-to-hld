# Contributing

1. Put content in its **exact level folder** (01 → 13). If it cuts across levels, put in `cross-cutting-concerns/` and link from each level.
2. One concept per file / folder. Every pattern or case study needs `README.md` (problem → design → diagram → trade-offs) + code or diagram in `assets/diagrams/`.
3. Kebab-case files/folders. Update parent `README.md` checklist + `docs/ARCHITECTURE-MAP.md` if you add a level-wide concept.
4. Example changes go in `examples/worldconnect/` mapped to levels, not scattered.
5. Keep PRs small: what + why + level number.
