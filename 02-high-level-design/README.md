# 02 — High-Level Design

System-level design. Goal: design scalable, reliable distributed systems.

## Contents

- `01-fundamentals/` — scalability, latency/throughput, CAP, consistency, estimations
- `02-building-blocks/` — load balancer, caching, CDN, messaging, rate limiting, ID gen

For each case study: requirements → estimations → API → data model → high-level diagram → deep dives → bottlenecks.
