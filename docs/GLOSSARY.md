# Glossary

| Term | Short definition |
|------|------------------|
| LLD | Class-level design: classes, interfaces, relationships, patterns |
| HLD | System-level design: services, data flow, scaling, reliability |
| UML | Unified Modeling Language — class, sequence diagrams |
| SOLID | Single responsibility, Open/closed, Liskov, Interface segregation, Dependency inversion |
| CAP | Consistency, Availability, Partition tolerance — pick 2 |
| Throughput | Requests / sec the system handles |
| Latency | Time per request |
| Horizontal scaling | Add more machines |
| Vertical scaling | Bigger machine |
| Sharding | Splitting data across DB nodes |
| Replication | Copying data for availability / read scale |
